## ℹ️ Примечание о модели

Использована модель `Qwen/Qwen2.5-1.5B-Instruct` вместо `Llama-3.2-1B`, 
так как запрос на доступ к Llama был отклонён, а повторная подача невозможна 
из-за технических ограничений платформы.

**Обоснование выбора:**
- Архитектура аналогична Llama (GQA, RoPE, SwiGLU)
- Размер 1.5B параметров (сопоставимо с 1B)
- Полностью открытая лицензия (Apache 2.0)
- Демонстрирует тот же метод: LoRA fine-tuning на SQuAD 2.0

**Результаты:**
- Методика полностью воспроизводима для любой causal LM
- При получении доступа к Llama достаточно заменить `model_name` в коде
