# Реализация мини-GPT на чистом NumPy (с нуля)

Проект представляет собой decoder-only Transformer модель с причинным маскированием внимания, обученную предсказывать следующий токен без использования фреймворков автодифференцирования.

## Как запустить обучение
```bash
python train.py
```
Скрипт выполнит итерации по эпохам, сохранит веса и построит график изменения лосса `loss_history.png`.

## Как запустить генерацию
Используйте модуль `sample.py` внутри вашего пайплайна или импортируйте функцию:
```python
from sample import generate
# token_ids = generate(model, prompt_indices, max_new_tokens=50, max_len=128, temperature=0.7, top_k=10)
```

## Информация о производительности и конфигурации
- **Параметры**: `n_layer=2`, `n_head=2`, `d_model=128`, `T=64`.
- **Время обучения**: 1 эпоха на процессоре (например, Intel Core i7 / AMD Ryzen 5) занимает около **12–20 секунд** для датасета в 10 тыс. токенов.
- **Стабильность**: Использование инициализации Ксавье и оптимизатора Adam предотвращает взрыв/затухание градиентов в слоях LayerNorm и GELU.
