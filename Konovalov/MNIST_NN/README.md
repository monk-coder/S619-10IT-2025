# Нейронная сеть для классификации рукописных цифр MNIST

Реализация нейронной сети с нуля для классификации рукописных цифр из датасета MNIST.

## Особенности

- Полная реализация forward и backward propagation с нуля
- Обучение с помощью градиентного спуска
- Визуализация процесса обучения
- Настройка гиперпараметров
- Оценка производительности модели
