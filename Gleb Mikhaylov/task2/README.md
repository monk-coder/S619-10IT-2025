# Дашборд погоды с задачами

Веб-приложение для поиска погоды и управления персональными задачами, связанными с погодными условиями.

## Функциональность

### 🌤️ Поиск погоды
- Поиск текущей погоды по городу через OpenWeatherMap API
- Отображение температуры, влажности, погодных условий и иконки
- Кэширование данных с обновлением каждые 2 часа
- Обработка ошибок API (город не найден, превышен лимит, недоступен сервис)

### 📝 Управление задачами
- Создание, просмотр, редактирование и удаление персональных задач
- Связывание задач с определенными городами
- Приоритеты задач (низкий, средний, высокий)
- Статусы задач (ожидает, в процессе, завершена, отменена)
- Фильтрация и поиск по задачам

### 👤 Аутентификация
- Регистрация новых пользователей
- Вход в систему
- Управление сессией
- Персональные данные для каждого пользователя

### 📊 Дашборд
- Общая статистика задач пользователя
- Последние задачи и история поиска
- Быстрые действия

### 📈 История поиска
- Сохранение истории поиска городов для каждого пользователя
- Отображение последних поисковых запросов

## Технические требования

- **Backend**: Django 4.2+ с ORM
- **База данных**: SQLite (по умолчанию), PostgreSQL, MySQL
- **Frontend**: HTML шаблоны с Bootstrap 5
- **API**: OpenWeatherMap API
- **Кэширование**: Встроенное кэширование Django

## Установка и запуск

### 1. Клонирование и установка зависимостей

```bash
# Установка зависимостей
pip install -r requirements.txt
```

### 2. Настройка окружения

Создайте файл `.env` на основе `env_example.txt`:

```bash
cp env_example.txt .env
```

Отредактируйте `.env` файл и добавьте ваш API ключ OpenWeatherMap:

```
OPENWEATHER_API_KEY=ваш_api_ключ_здесь
```

### 3. Получение API ключа OpenWeatherMap

1. Зарегистрируйтесь на [OpenWeatherMap](https://openweathermap.org/api)
2. Получите бесплатный API ключ
3. Добавьте ключ в файл `.env`

### 4. Настройка базы данных

```bash
# Создание миграций
python manage.py makemigrations

# Применение миграций
python manage.py migrate

# Создание суперпользователя (опционально)
python manage.py createsuperuser
```

### 5. Запуск сервера

```bash
python manage.py runserver
```

Приложение будет доступно по адресу: http://127.0.0.1:8000/

## Модели данных

### WeatherTask
- Задачи пользователей, связанные с погодой
- Поля: название, описание, город, приоритет, статус, срок выполнения

### SearchHistory
- История поиска городов пользователями
- Поля: пользователь, город, страна, дата поиска

### WeatherCache
- Кэширование погодных данных
- Поля: город, температура, влажность, описание, иконка, время кэширования

## API Endpoints

- `GET /` - Главная страница с поиском погоды
- `POST /` - Поиск погоды
- `GET /register/` - Регистрация пользователя
- `POST /register/` - Создание нового пользователя
- `GET /login/` - Страница входа
- `POST /login/` - Аутентификация пользователя
- `GET /logout/` - Выход из системы
- `GET /dashboard/` - Дашборд пользователя
- `GET /tasks/` - Список задач
- `GET /tasks/create/` - Создание задачи
- `POST /tasks/create/` - Сохранение новой задачи
- `GET /tasks/<id>/` - Детальный просмотр задачи
- `GET /tasks/<id>/edit/` - Редактирование задачи
- `POST /tasks/<id>/edit/` - Сохранение изменений задачи
- `GET /tasks/<id>/delete/` - Подтверждение удаления задачи
- `POST /tasks/<id>/delete/` - Удаление задачи
- `POST /tasks/<id>/update-status/` - Обновление статуса задачи (AJAX)
- `GET /history/` - История поиска

## Особенности реализации

### Кэширование погодных данных
- Данные кэшируются в базе данных на 2 часа
- При повторном запросе того же города данные берутся из кэша
- Автоматическое обновление при истечении срока кэша

### Обработка ошибок API
- Город не найден (404)
- Неверный API ключ (401)
- Превышен лимит запросов (429)
- Недоступность сервиса
- Пользовательские сообщения об ошибках

### Безопасность
- CSRF защита для всех форм
- Аутентификация для персональных данных
- Валидация пользовательского ввода
- Защита от SQL-инъекций через Django ORM

## Развертывание в продакшене

1. Установите переменную `DEBUG=False` в `.env`
2. Смените `SECRET_KEY` на случайную строку
3. Настройте базу данных PostgreSQL или MySQL
4. Соберите статические файлы: `python manage.py collectstatic`
5. Используйте WSGI сервер (например, Gunicorn) с веб-сервером (Nginx)
