# BPE (Byte Pair Encoding) Токенизатор

Реализация субсловного токенизатора на основе алгоритма Byte Pair Encoding (BPE) с нуля.

## Описание

Этот проект реализует BPE токенизатор, который разбивает текст на субсловные единицы, что позволяет эффективно обрабатывать редкие слова и уменьшать размер словаря. Токенизатор обучается на корпусе текстов и может кодировать произвольный текст в последовательность идентификаторов токенов и декодировать обратно.

## Особенности

- Полная реализация BPE с нуля на чистом Python
- Поддержка Unicode и кириллицы
- Сохранение и загрузка обученных моделей
- Интерактивный и пакетный режимы работы
- Визуализация результатов и метрик
- Проверка корректности: `decode(encode(text)) == text`
