# 🌐 Умный многоязычный переводчик

Простой и удобный графический переводчик с поддержкой 20+ языков на базе Tkinter и Google Translate API.

![Интерфейс переводчика](https://via.placeholder.com/800x500/f5f7fa/2c3e50?text=Smart+Translator+GUI)

## ✨ Возможности

- 🌍 Поддержка 20+ популярных языков (русский, английский, испанский, французский, немецкий и др.)
- 🔍 Автоматическое определение языка исходного текста
- 🔄 Быстрый обмен языками и текстами кнопкой ⇄
- 📝 Многострочный ввод с прокруткой
- ⚡ Асинхронный перевод (интерфейс не зависает)
- 💡 Горячие клавиши: `Enter` — перевести, `Ctrl+L` — очистить
- 🎨 Современный и интуитивно понятный интерфейс

## 📦 Требования

- Python 3.7 или новее
- Интернет-соединение (для работы Google Translate API)
