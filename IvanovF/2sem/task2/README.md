# Простая нейросеть для MNIST

Это очень простая нейросеть, сделанная без сложных библиотек.

## Как запустить

1. Установить зависимости:

pip install -r requirements.txt

2. Запустить программу:

python main.py

## Что делает программа

- Загружает картинки цифр
- Обучает простую нейронку
- Показывает точность
- Строит графики
