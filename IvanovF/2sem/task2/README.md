# MNIST Neural Network (с нуля)

Реализация полносвязной нейронной сети без использования фреймворков глубокого обучения.

## Возможности
- Forward / Backpropagation вручную
- Обучение градиентным спуском
- Графики loss и accuracy
- Точность > 60% (обычно 90%+)
