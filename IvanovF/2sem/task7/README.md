# RAG-система для QA над документами

Retrieval-Augmented Generation (RAG) система: пользователь задаёт вопрос — система ищет релевантные фрагменты из PDF-документов и генерирует ответ с опорой на них.

**Стек:** LangChain + FAISS + sentence-transformers + Ollama  
**Работает полностью локально на CPU**

---

## Структура проекта

```
rag-system/
├── rag_qa.py              # основной скрипт (интерактивный чат)
├── data_preprocessing.py  # PDF → chunks → FAISS индекс
├── rag_pipeline.py        # retrieval + LLM
├── evaluate.py            # 10 тест-вопросов + оценка
├── docs/                  # сюда кладите ваши PDF
├── faiss_index/           # сохранённый индекс (создаётся автоматически)
├── requirements.txt
└── README.md
```

## Установка

### 1. Установить зависимости Python

```bash
pip install -r requirements.txt
```

### 2. Установить Ollama и скачать модель

Скачать Ollama с сайта: https://ollama.com

```bash
ollama pull llama3.2:1b
```

Убедитесь, что Ollama запущена перед использованием системы.

## Использование

### Шаг 1: Добавить PDF-документы

Положите ваши PDF-файлы в папку `docs/`:

```
docs/
├── lecture1.pdf
├── lecture2.pdf
└── ...
```

### Шаг 2: Создать индекс

```bash
python data_preprocessing.py
```

Скрипт:
- Загружает все PDF из папки `docs/`
- Разбивает текст на чанки (≈500 токенов, overlap ≈50 токенов)
- Создаёт эмбеддинги с помощью `all-MiniLM-L6-v2`
- Сохраняет FAISS индекс в папку `faiss_index/`

### Шаг 3: Запустить чат

```bash
python rag_qa.py
```

Пример работы:
```
> Вопрос: Что такое causal mask в Transformer?

[Источник 1]: lecture3.pdf, стр. 12
[Источник 2]: lecture4.pdf, стр. 5
[Источник 3]: lecture2.pdf, стр. 3

Ответ: Causal mask — это маска, которая не позволяет...
```

Для выхода введите `выход` или `exit`.

### Шаг 4: Оценить качество

```bash
python evaluate.py
```

Скрипт задаёт 10 вопросов, показывает ответы системы и просит вас оценить каждый вручную по двум критериям:
- **Faithfulness (0/1):** ответ основан на источниках?
- **Relevance (0/1):** источники релевантны вопросу?

В конце выводится итоговый отчёт.

---

## Как добавить свои вопросы в evaluate.py

Откройте `evaluate.py` и замените заглушки в списке `TEST_QUESTIONS`:

```python
TEST_QUESTIONS = [
    "Что такое causal mask в Transformer?",
    "Как работает механизм attention?",
    # ... и так далее
]
```

## Технические детали

| Параметр | Значение |
|---|---|
| Модель эмбеддингов | `all-MiniLM-L6-v2` |
| Размер чанка | 2000 символов (≈500 токенов) |
| Перекрытие чанков | 200 символов (≈50 токенов) |
| Количество источников | top-3 |
| LLM | `llama3.2:1b` через Ollama |
