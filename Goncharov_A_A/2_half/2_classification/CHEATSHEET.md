## 🧠 Архитектура сети

```
Вход (784) → Скрытый слой (128, ReLU) → Выход (10, Softmax)
```

**Параметры:**
- W1: 784 × 128 = 100,352
- b1: 128
- W2: 128 × 10 = 1,280
- b2: 10
- **Всего:** 101,770 параметров

---

## 📐 Forward Propagation (Прямое распространение)

```
Z1 = X @ W1 + b1          # Линейное преобразование
A1 = ReLU(Z1)              # Активация скрытого слоя
Z2 = A1 @ W2 + b2          # Линейное преобразование
A2 = Softmax(Z2)           # Активация выходного слоя
```

**ReLU:** `ReLU(x) = max(0, x)`

**Softmax:** `softmax(z_i) = exp(z_i - max(z)) / Σexp(z_j - max(z))`

---

## 📉 Loss Function (Функция потерь)

**Cross-Entropy Loss:**
```
L = -1/m * Σ Σ(y_true * log(y_pred))
```

**Интерпретация:**
- Если предсказание идеальное (вероятность = 1.0): L = 0
- Если предсказание плохое (вероятность = 0.01): L = 4.6

---

## ⬅️ Backpropagation (Обратное распространение)

### Градиенты выходного слоя:
```
dZ2 = A2 - y_true
dW2 = (A1^T @ dZ2) / m
db2 = sum(dZ2) / m
```

### Градиенты скрытого слоя:
```
dA1 = dZ2 @ W2^T
dZ1 = dA1 * ReLU'(Z1)      # ReLU'(x) = 1 если x > 0, иначе 0
dW1 = (X^T @ dZ1) / m
db1 = sum(dZ1) / m
```

### Обновление весов:
```
W = W - learning_rate × dW
b = b - learning_rate × db
```

## 🎯 Ключевые концепции

### Что такое градиент?
**Градиент** показывает направление, в котором нужно изменить веса, чтобы уменьшить ошибку.

### Почему ReLU?
- Быстро вычисляется
- Устраняет затухающие градиенты (для положительных значений)
- Добавляет нелинейность

### Почему Softmax?
- Преобразует числа в вероятности (сумма = 1)
- Идеально для многоклассовой классификации
- Хорошо работает с Cross-Entropy

### Почему Cross-Entropy?
- Сильно штрафует уверенные неправильные предсказания
- Простая производная с Softmax: `dL/dZ = A - y_true`
- Интерпретируемый результат (информация)

### Почему Mini-batch?
- **Быстрее**, чем Batch GD (обновление на каждом батче)
- **Стабильнее**, чем Stochastic GD (усреднение по батчу)
- **Эффективнее** по памяти

### Почему важна инициализация?
- **Плохая инициализация** → затухающие/взрывающиеся градиенты
- **He initialization** (для ReLU): `W ~ N(0, sqrt(2/n_input))`
- **Xavier initialization**: `W ~ N(0, sqrt(1/n_input))`

## 💡 Быстрые ответы на вопросы

**Q: Как работает forward propagation?**
A: Данные проходят через сеть: вход → линейное преобразование → активация → выход. Результат - вероятности классов.

**Q: Как работает backpropagation?**
A: Ошибка распространяется назад от выхода к входу. Вычисляем градиенты для каждого слоя, используя цепное правило.

**Q: Что такое градиентный спуск?**
A: Алгоритм оптимизации. Обновляем веса в направлении, противоположном градиенту: `W = W - lr × gradient`.

**Q: Зачем нужны функции активации?**
A: Добавляют нелинейность. Без них сеть - просто линейная функция и не может решать сложные задачи.

**Q: Почему именно такая архитектура?**
A: Двухслойная сеть с 128 нейронами - баланс между сложностью и скоростью. ReLU ускоряет обучение, Softmax дает вероятности.
