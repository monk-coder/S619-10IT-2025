# BPE Tokenizer - Полная реализация

Полная реализация субсловного токенизатора на основе Byte Pair Encoding (BPE) с нуля.

## Быстрый старт

```bash
# Клонируйте репозиторий или создайте файлы вручную
# Перейдите в папку BPE
cd BPE

# Установите зависимости
pip install -r requirements.txt

# Запустите полный эксперимент одной командой
python run_experiment.py
