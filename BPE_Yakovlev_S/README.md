## Что такое BPE?

**Byte Pair Encoding (BPE)** — алгоритм сегментации текста, решающий проблему редких и неизвестных слов путём разбиения их на субсловные единицы (например, `"недопустимый"` → `["не", "до", "пуст", "им", "ый"]`).

Алгоритм:
1. Инициализация на уровне отдельных символов Unicode.
2. Итеративное слияние самых частых пар соседних токенов.
3. После `num_merges` итераций получаем словарь, содержащий символы и часто встречающиеся подстроки.

Подробнее: [Sennrich et al., 2016 — Neural Machine Translation of Rare Words with Subword Units](https://arxiv.org/abs/1508.07909)

## Функциональность

- ✅ Обучение токенизатора на текстовом корпусе
- ✅ Кодирование текста в последовательность целочисленных ID (`encode()`)
- ✅ Декодирование ID обратно в исходный текст (`decode()`)
- ✅ Сохранение/загрузка модели в/из JSON
- ✅ Строгая обратимость: `decode(encode(text)) == text` для любого текста из валидации
- ✅ Автоматический расчёт метрик и визуализация влияния `num_merges`
