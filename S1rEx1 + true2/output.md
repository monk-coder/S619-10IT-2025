# Telegram Bot "Второй мозг" - Объяснение проекта

## Что это?
Telegram бот-ассистент для обучения с AI, который может сохранять заметки, отвечать на вопросы и обучать новым темам.

## Архитектура

### Основные файлы:
- **bot.py** - точка входа, запускает бота
- **config.py** - конфигурация (токены, настройки)
- **database.py** - база данных SQLite (пользователи, заметки, сообщения)
- **openrouter_client.py** - работа с AI через OpenRouter API
- **prompts.py** - системные промпты для AI
- **document_processor.py** - обработка PDF и изображений (OCR)

### Структура bot_app/:
- **application.py** - главный класс бота, инициализация handlers
- **handlers/** - обработчики команд (/start, профиль, заметки, инструктор)
- **constants.py** - состояния бота (меню, профиль, заметки и т.д.)
- **models_config.py** - доступные AI модели (DeepSeek V3, DeepSeek R1, Qwen 3 Coder, Llama 3.3)

## Как работает?

### 1. Запуск
```bash
export TELEGRAM_BOT_TOKEN=ваш_токен
export OPENROUTER_API_KEY=ваш_ключ
python3 bot.py
```

### 2. База данных
- **Users** - информация о пользователях, их настройки (кастомные промпты, модель, temperature)
- **Notes** - заметки пользователей с AI-суммаризацией
- **Conversations** - истории диалогов
- **Messages** - все сообщения с токенами

### 3. Режимы работы

#### Общий режим
- Просто пишешь сообщение → бот отвечает через AI
- Использует историю последних 10 сообщений для контекста
- Применяет кастомный промпт пользователя (если установлен)

#### Режим заметок
1. Отправляешь PDF или фото
2. Бот извлекает текст (OCR для фото, PyPDF2 для PDF)
3. AI создаёт краткую суммаризацию
4. Сохраняет в базу для дальнейшего использования

#### Режим инструктора
1. Выбираешь тему обучения
2. Задаёшь вопрос
3. AI отвечает как преподаватель (адаптируется под уровень)

#### Профиль
- Настройка кастомного промпта
- Выбор AI модели (DeepSeek, Llama, Qwen)
- Дополнительные инструкции
- Статистика использования

## Откуда берутся промпты?

### Системные промпты (prompts.py):
- **GENERAL_ASSISTANT_PROMPT** - для обычных диалогов
- **summary_system_prompt()** - для суммаризации текстов
- **image_extraction_system_prompt()** - для обработки изображений
- **contextual_answer_system_prompt()** - для ответов с контекстом
- **instructor_system_prompt()** - для режима обучения

### Пользовательские промпты:
- Хранятся в БД (таблица Users, поле custom_prompt)
- Устанавливаются через меню "Профиль → Настроить промпт"
- Применяются ко всем ответам AI для этого пользователя

### Как формируется финальный промпт:
```python
system_prompt = user.custom_prompt or GENERAL_ASSISTANT_PROMPT
if user.specific_instructions:
    system_prompt += f"\n\n{user.specific_instructions}"
```

## AI Модели
Используется OpenRouter API с бесплатными моделями:
- **DeepSeek V3** (по умолчанию) - универсальная
- **DeepSeek R1** - с улучшенными рассуждениями
- **Qwen 3 Coder** - для программирования
- **Llama 3.3 70B** - большая модель от Meta

## Обработка документов

### PDF:
- PyPDF2 извлекает текст постранично
- Лимит 10 MB
- AI создаёт краткую суммаризацию

### Изображения:
- Tesseract OCR (eng+rus)
- Лимит 5 MB
- Извлекает текст с фото/скриншотов

## Rate Limiting
- **10 запросов/минуту** на пользователя
- **100 запросов/минуту** глобально
- Реализовано через aiolimiter

## Особенности
- Асинхронная архитектура (async/await)
- Conversation history для контекста
- Markdown форматирование ответов
- Поддержка streaming ответов
- Логирование всех операций
