НЕЙРОННАЯ СЕТЬ ДЛЯ КЛАССИФИКАЦИИ РУКОПИСНЫХ ЦИФР (MNIST)
📋 О проекте
Полная реализация нейронной сети с нуля на Python для классификации рукописных цифр из датасета MNIST. Проект включает все основные компоненты машинного обучения: прямого и обратного распространения, градиентного спуска, оценки производительности.

🎯 Основные возможности
✅ Реализация нейронной сети с нуля (без использования TensorFlow/PyTorch)

✅ Алгоритмы прямого и обратного распространения (forward/backward propagation)

✅ Обучение с помощью стохастического градиентного спуска (SGD)

✅ Визуализация процесса обучения (графики потерь и точности)

✅ Оценка производительности модели

✅ Настройка гиперпараметров

Оптимизатор: SGD с моментумом

Инициализация весов: метод Xavier/Glorot

📚 Теоретическая основа
Проект реализует следующие алгоритмы:

1. Прямое распространение (Forward Propagation)
Линейное преобразование: z = W·x + b

Нелинейная активация: ReLU/Softmax

2. Обратное распространение (Backpropagation)
Вычисление градиентов методом цепного правила

Обновление весов: W = W - η·∇W

3. Оптимизация
Стохастический градиентный спуск (SGD)

Моментум для ускорения сходимости

🐛 Возможные проблемы и решения
Проблема: Ошибка импорта pandas
Решение:

bash
pip install pandas
Или использовать версию кода с параметром as_frame=False

Проблема: Долгое обучение
Решение:
Уменьшить параметры в main.py:

python
EPOCHS = 5           # Вместо 10
HIDDEN_SIZE = 64     # Вместо 128
BATCH_SIZE = 32      # Вместо 64
Проблема: Низкая точность
Решение:

Увеличить количество эпох

Настроить скорость обучения

Добавить больше нейронов в скрытый слой
