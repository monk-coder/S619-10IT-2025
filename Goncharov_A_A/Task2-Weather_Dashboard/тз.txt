- **Дашборд погоды с задачами**
    
    Функциональные требования
    
    - Пользователи могут искать текущую погоду по городу с помощью OpenWeatherMap API (или аналогичного бесплатного погодного API).
    - На дашборде отображаются текущая температура, влажность, погодные условия и иконка для выбранного города.
    - Аутентифицированные пользователи могут сохранять напоминания/задачи, связанные с погодой (например, «Взять зонт, если прогнозируется дождь»), связанные с определёнными городами и хранящиеся в базе данных.
    - Операции CRUD (создание, просмотр, обновление, удаление) для персональных задач; задачи видны только владельцу.
    - Панель истории поиска отображает последние города, введённые пользователем (история хранится в БД отдельно для каждого пользователя).
    - При ошибке внешнего API (город не найден, превышен лимит, недоступен сервис) в интерфейсе показывается соответствующее сообщение.
    
    Технические требования
    
    - Backend на Python: Django или FastAPI.
        - **Django**: использовать ORM для моделей пользователей, задач, истории городов; рендерить страницы через HTML-шаблоны.
        - **FastAPI**: применять SQLAlchemy или Tortoise ORM; реализовать REST API; фронтенд на React/Vue как SPA.
    - Получение погодных данных cо стороннего API не реже чем 1 раз в 2 часа
    - Хранение информации о пользователях, задачах и истории поиска в БД (SQLite/PostgreSQL/MySQL).
    - Реализовать регистрацию, вход, и управление сессией.
    - Погода запрашивается с бэкэнда онлайн, но бэкэнд обновляет данные с определённой периодичностью; опционально можно кэшировать с отметкой времени.- **Дашборд погоды с задачами**
