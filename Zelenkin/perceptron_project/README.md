input_size: сколько входов у перцептрона (для AND = 2)

learning_rate: скорость обучения (по умолчанию 0.1)

activation(): Превращает любое число в 0 или 1.

train(): Выводит начальные параметры.

1. Входные данные → predict() → взвешенная сумма → activation() → предсказание
2. Сравнение предсказания с правильным ответом → ошибка
3. Ошибка → корректировка весов и смещения
4. Повтор 1-3 для всех примеров → это 1 эпоха
5. Повтор эпох пока ошибка не станет 0

Новый_вес = Старый_вес + learning_rate * error * вход

error = правильный_ответ - предсказание

Если error = 1:   # Должен быть 1, а предсказали 0
    weight += learning_rate * вход   # Увеличиваем вес

Если error = -1:  # Должен быть 0, а предсказали 1
    weight -= learning_rate * вход   # Уменьшаем вес

Если error = 0:   # Угадали
    weight не меняется              # Все и так хорошо

    Пример обучения за 2 эпохи:
    Пример [1,1], target=1: predict=0, error=1
Обновляем: w1=0.1+0.1*1*1=0.2, w2=0.1+0.1=0.2, bias=-0.1+0.1=0

Пример [0,1], target=0: predict=1 (0.2*0+0.2*1+0=0.2>=0), error=-1
Обновляем: w1=0.2+0.1*(-1)*0=0.2, w2=0.2+0.1*(-1)*1=0.1, bias=0+0.1*(-1)=-0.1

Теперь перцептрон стал умнее!
Все примеры предсказываются правильно → ошибка=0 → обучение завершено
