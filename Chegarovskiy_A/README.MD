# Mini-LLM на PyTorch: оптимизация и эксперименты

## 1. Бенчмарки

### 1.1 Скорость (PyTorch vs NumPy)

| Backend | It/s | Ускорение |
|---------|------|-----------|
| NumPy (Задание 4) | 2.1 | 1x |
| PyTorch CPU | 18.7 | 8.9x |
| **PyTorch GPU (RTX 3050)** | **35.2** | **16.8x** |

### 1.2 Масштабирование (GPU, batch_size)

| Batch size | It/s | Speedup vs BS=16 |
|------------|------|------------------|
| 16 | 25.1 | 1x |
| 32 | 32.8 | 1.31x |
| **64** | **35.2** | **1.40x** |
| 128 | 37.5 | 1.49x |

**Вывод:** Оптимальный batch_size = 64–128 для баланса скорости и памяти.

---

## 2. Эксперименты по качеству

### 2.1 Влияние языка и размера словаря

| Эксперимент | BPE | Vocab size | Итераций | Лучший PPL |
|-------------|-----|------------|----------|------------|
| Русская модель | самодельный (русский) | 8,140 | 15,000 | 126.8 |
| **Английская модель** | самодельный (английский) | 8,200 | 7,000 | 92.3 |
| **Английская модель (GPT-2 BPE)** | предобученный (GPT-2) | **50,257** | **7,000** | **17.7** |

**Вывод:** Использование предобученного BPE с большим словарём ускоряет падение PPL **в 7 раз**.

### 2.2 Perplexity по итерациям (английская модель, GPT-2 BPE)

| Итерации | Train Loss | Val Loss | PPL |
|----------|------------|----------|-----|
| 500 | 4.58 | 4.50 | 90.2 |
| 1,000 | 3.79 | 3.85 | 46.8 |
| 2,000 | 3.51 | 3.55 | 34.6 |
| 3,000 | 3.14 | 3.30 | 27.1 |
| 4,000 | 3.16 | 3.17 | 23.9 |
| 5,000 | 2.88 | 3.05 | 21.2 |
| 6,000 | 2.73 | 2.95 | 19.1 |
| **7,000** | **2.56** | **2.87** | **17.7** |

**Тренд:** PPL снижается экспоненциально. Достижение PPL < 9 ожидается на 15,000–20,000 итерациях.

---

## 3. Влияние размера модели

| Конфигурация | d_model | n_layer | Память (GB) | Статус |
|--------------|---------|---------|-------------|--------|
| Малая | 256 | 3 | ~4.5 | ✅ работает |
| **Средняя** | **384** | **4** | **~6.0** | ✅ работает |
| Большая | 512 | 4 | ~8.5 | ❌ OOM на 6k шагов |

**Вывод:** Для RTX 3050 8GB оптимальная конфигурация: d_model=384, n_layer=4, batch_size=8.

---

## 4. Требования

```bash
pip install -r requirements.txt
```

5. Запуск

```bash
# Обучение
python train.py --d_model 384 --n_layer 4 --batch_size 8 --device cuda

# Генерация
python sample.py --prompt "The" --tokens 50 --d_model 384 --n_layer 4
```
