# MNIST Neural Network from Scratch

Простая реализация нейронной сети на чистом NumPy для классификации рукописных цифр.

## Описание
Проект реализует двуслойную нейронную сеть (MLP):
- **Вход:** 784 (изображения 28x28)
- **Скрытый слой:** 128 (ReLU)
- **Выход:** 10 (Softmax)
- **Обучение:** Градиентный спуск (Batch Gradient Descent)
