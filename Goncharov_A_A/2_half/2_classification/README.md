# Нейронная сеть для классификации рукописных цифр MNIST

Программа для распознавания рукописных цифр (0-9) изображений. Задача классификации - программа смотрит на изображение цифры и говорит, какая это цифра.

Датасет MNIST содержит 70,000 изображений:
- 60,000 изображений для обучения
- 10,000 изображений для тестирования
- Каждое изображение: 28×28 пикселей (черно-белое)
- Классы: цифры от 0 до 9

Реализуем все алгоритмы самостоятельно:
- Прямое распространение (forward propagation)
- Обратное распространение (backpropagation)
- Градиентный спуск
- Функции активации
- Функции потерь

Используем только NumPy для матричных операций. Датасет MNIST скачивается автоматически.

## Структура нейронной сети

Сеть состоит из 3 слоев:

ВХОДНОЙ СЛОЙ → СКРЫТЫЙ СЛОЙ → ВЫХОДНОЙ СЛОЙ
(784 нейрона) → (128 нейронов) → (10 нейронов)

- Входной слой: каждый нейрон соответствует одному пикселю изображения (28×28 = 784)
- Скрытый слой: обработка данных с функцией активации ReLU
- Выходной слой: вероятности для каждой цифры (0-9) с функцией Softmax

## Обучение

Обучение проходит по следующему принципу:

1. Прямое распространение: данные проходят через сеть
2. Вычисление ошибки: сравнение предсказаний с правильными ответами
3. Обратное распространение: вычисление того, как изменить веса, чтобы уменьшить ошибку
4. Обновление весов: корректировка параметров сети

Этот процесс повторяется 50 раз (50 эпох), каждый раз обрабатывая данные по частям (батчи по 128 изображений).
