### Задача

Вы должны реализовать **с нуля** субсловный токенизатор на основе Byte Pair Encoding (BPE) и полный текстовый пайплайн: обучение токенизатора на корпусе, кодирование текста в последовательность id и обратное декодирование. Подход «редкие слова как последовательности субслов» широко используется в NLP/LLM и описан, например, в работе Sennrich et al. про subword units и BPE-сегментацию.

### Что нужно сделать

- Подготовка данных:
    - Вход: один файл `data.txt` (UTF-8) — текстовый корпус (находится в паке `0`).
    - Разбиение на `train/val` и сохранение списков строк/документов.
- Реализация обучения BPE:
    - Инициализация «словаря символов» (на уровне символов Unicode; можно ограничиться теми символами, что встречаются в `train`).
    - Итеративные слияния: на каждом шаге находить самую частую пару соседних токенов и заменять её новым токеном; параметр `num_merges`.
    - Сохранение правил слияний (merges) в файл (например, `bpe_merges.json`).
- Реализация `encode(text) -> list[int]` и `decode(ids) -> str`:
    - `encode`: применять merges и выдавать id из словаря.
    - `decode`: восстанавливать строку обратно.
    - Требование: `decode(encode(text)) == text` для любого текста из `val` (строгое равенство).
- Метрики/анализ:
    - Посчитать: размер словаря, среднюю длину последовательности токенов (в токенах) на `val`, долю «очень длинных» токенизаций (например, top-1% по длине).
    - Провести небольшой эксперимент: сравнить 2–3 значения `num_merges` (например, 0 / 2k / 8k) и показать, как меняется средняя длина.

### Требования к коду

1. Python + numpy (допускаются: `numpy`, `regex` или стандартный `re`, `tqdm`, `matplotlib`; запрещены: PyTorch/TensorFlow/JAX).
2. Код организован в логические функции/классы, минимум:
    - `BPETokenizer.train(corpus, num_merges)`
    - `BPETokenizer.encode(text)`
    - `BPETokenizer.decode(ids)`
    - `save/load` (чтобы не переобучать токенизатор каждый запуск)
3. Файл `README.md` с инструкциями по установке и запуску + примерами encode/decode.
4. `requirements.txt`.
5. Код должен быть загружен в вашу папку. Все файлы поместите в под-папку с названием `BPE`
### Как происходит защита

1. Преподаватель запускает ваш код на чистом окружении по README.
2. Автопроверка корректности:
    - `decode(encode(x)) == x` на наборе тестовых строк.
    - Время обучения токенизатора на предоставленном корпусе не должно превышать разумный лимит (несколько минут).
3. Code-review: читаемость, структура, отсутствие квадратичных узких мест там, где можно сделать быстрее.
4. 2–3 вопроса по теме
