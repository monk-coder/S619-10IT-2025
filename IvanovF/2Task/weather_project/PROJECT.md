# ДешТер

## Общий обзор

Приложение представляет собой веб‑страницу, стилизованную под терминал, которая общается с backend на Django. Через текстовые команды можно авторизоваться, узнавать погоду и статус рейсов, управлять личными задачами, конвертировать валюту. Интерфейс повторяет ощущения работы в консоли: ввод команды, вывод ответа, история, автодополнение.

## Как устроен сайт

- **Backend (Django)** отдаёт HTML-шаблоны и JSON‑эндпоинты. Здесь живёт аутентификация, API погоды, рейсов, валют и задач.
- **Frontend (JavaScript)** построен вокруг пространства имён `TerminalApp`. Центральный файл `terminal-commands.js` регистрирует команды, перехватчики ввода и подсказки автодополнения. Каждая команда подключается отдельным файлом в `weather/static/weather/js/commands/`.
- **Шаблон** `weather/templates/weather/index.html` подключает все скрипты, а стили находятся в `weather/static/weather/css/`.

## Команды терминала

| Команда | Назначение |
| --- | --- |
| `help` | Показывает список доступных команд. |
| `clear` | Очищает историю вывода. |
| `fetch` | Рисует «неофетч» ASCII-баннер с фиктивной системной информацией. |
| `signup <логин> <пароль>` | Создаёт нового пользователя и загружает историю/задачи. |
| `login <логин> <пароль>` | Авторизует пользователя и обновляет приглашение. |
| `logout` | Завершает сессию и сбрасывает локальные данные. |
| `timezone <смещение>` | Задает новый часовой пояс (например, `timezone +3`). |
| `timer <секунды>` | Запускает секундомер с обратным отсчётом. |
| `note <текст>` | Сохраняет локальную заметку в `localStorage`. |
| `notes` | Показывает все локальные заметки. |
| `tasks` | Загружает и отображает напоминания пользователя. |
| `taskadd <город>|<текст>` | Создаёт новое напоминание о погоде. |
| `taskupdate <id>|<город>|<текст>` | Обновляет существующую задачу. |
| `taskdelete <id>` | Удаляет задачу по идентификатору. |
| `weather <город>` | Получает текущую погоду по городу. |
| `flight <IATA>` | Возвращает информацию о рейсе по коду аэропорта. |
| `currency <из> [в] [сумма]` | Конвертирует валюты через backend API. |
| `admin` | Для staff-пользователей: краткая сводка по пользователям, задачам и поискам. |
| `casino` | Мини-игра с простыми слотами и рулеткой (выход — `q`). |

## Работа пользовательских функций

- **Управление аккаунтом:** Commands `signup`, `login`, `logout` общаются с `/api/auth/`, обновляя приглашение терминала и подтягивая историю запросов и задачи.
- **Задачи:** Вызовы `/api/tasks/` позволяют создавать и поддерживать напоминания о погоде, выводя их в таблицу.
- **Погода и рейсы:** REST-endpoints `/api/weather/` и `/api/flight/` возвращают данные, которые команда отрисовывает с минимальными ASCII‑элементами.
- **Валюты:** `/api/currency/` выдаёт курсы; команда подготавливает таблицу с конвертацией заданной суммы.


## Тестирование

Для запуска всех серверных тестов выполните:

```bash
python manage.py test
```

Команда поднимет временную базу данных, проверит сериализаторы, представления и модели, не затрагивая реальные данные.
