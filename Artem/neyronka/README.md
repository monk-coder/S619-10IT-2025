# MNIST Neural Network from Scratch

## Описание
Реализация полносвязной нейронной сети с нуля на Python для классификации рукописных цифр (0–9) из датасета MNIST.  
Используются только `numpy`, `matplotlib` и `scikit-learn` (только для загрузки данных).

## Установка
1. Клонируйте репозиторий.
2. Установите зависимости:
