# Нейронная сеть для классификации рукописных цифр MNIST

Реализация нейронной сети с нуля для классификации рукописных цифр из датасета MNIST.

## Особенности реализации

- **Алгоритмы машинного обучения с нуля**:
  - Прямое распространение (forward propagation)
  - Обратное распространение (backpropagation)
  - Градиентный спуск (gradient descent)
  - Регуляризация L2

- **Архитектура сети**:
  - Полносвязная нейронная сеть
  - ReLU активация для скрытых слоев
  - Softmax активация для выходного слоя
  - Настраиваемая архитектура (количество и размер скрытых слоев)

- **Визуализация**:
  - Графики обучения (потери и точность)
  - Матрица ошибок
  - Примеры предсказаний
