⚙️ Параметры обучения

Базовая команда

```bash
python train.py
```

Свои параметры

```bash
# Глубокая сеть
python train.py --layers 784,256,128,10 --epochs 30

# Быстрое тестирование
python train.py --epochs 5 --batch_size 128

# Точная настройка
python train.py --lr 0.005 --reg 0.0005 --batch_size 64
```

Все параметры:

· --layers — размеры слоев через запятую (по умолчанию: "784,128,10")
· --lr — скорость обучения (по умолчанию: 0.01)
· --epochs — количество эпох (по умолчанию: 20)
· --batch_size — размер батча (по умолчанию: 32)
· --reg — L2 регуляризация (по умолчанию: 0.001)
· --val_size — размер валидационной выборки (по умолчанию: 5000)
· --seed — seed для воспроизводимости (по умолчанию: 42)

🧠 Архитектура сети

Стандартная архитектура: 784 → 128 → 10

· Вход: 784 нейрона (28×28 пикселей)
· Скрытый слой: 128 нейронов с активацией ReLU
· Выход: 10 нейронов с активацией Softmax (цифры 0-9)

Всего обучаемых параметров: 101,770

🔧 Технические детали

Реализовано:

· ✅ Forward propagation (прямое распространение)
· ✅ Backward propagation (обратное распространение)
· ✅ Gradient descent с мини-батчами
· ✅ Cross-entropy loss с L2 регуляризацией
· ✅ ReLU для скрытых слоев, Softmax для выхода
· ✅ One-hot encoding меток
· ✅ Автоматическая загрузка MNIST

Алгоритмы:

1. Forward pass: Z = W·X + b, A = relu(Z)
2. Loss: CrossEntropy + L2 регуляризация
3. Backward pass: расчет градиентов по цепному правилу
4. Weight update: W = W - lr * dW

❓ Частые вопросы

Как работает forward propagation?

Умножение входных данных на веса, добавление смещения, применение функции активации.

Как работает backward propagation?

Расчет градиентов ошибки относительно каждого веса с использованием цепного правила.

Что такое learning rate?

Шаг обновления весов. Контролирует скорость обучения.

Почему точность не 100%?

Некоторые цифры визуально похожи (5/6, 3/8). 96% — отличный результат для реализации с нуля.
