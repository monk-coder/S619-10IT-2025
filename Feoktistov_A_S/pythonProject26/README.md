# Нейронная сеть для классификации рукописных цифр (MNIST)

Реализация нейронной сети с нуля для классификации цифр из датасета MNIST.

## Особенности
- Полная реализация с нуля на Python/NumPy
- Прямое и обратное распространение
- Градиентный спуск с мини-батчами
- Регуляризация L2
- Визуализация процесса обучения
