# 🌤️ AetherWeather - Погодный Дашборд

Веб-приложение для поиска погоды и управления персональными задачами, связанными с погодными условиями.

## 📋 Функциональность

### 🌤️ Поиск погоды
- Поиск текущей погоды по городу через OpenWeatherMap API
- Отображение температуры, влажности, погодных условий и иконки
- Кэширование данных с обновлением каждые 2 часа
- Обработка ошибок API (город не найден, недоступен сервис)

### 📝 Управление задачами
- Создание, просмотр и удаление персональных задач
- Связывание задач с определенными городами
- Отметка выполнения задач
- Фильтрация задач по городам

### ⭐ Избранные города
- Добавление городов в избранное для быстрого доступа
- Управление списком избранных городов
- Быстрый поиск погоды по избранным городам

### 👤 Аутентификация и персонализация
- Регистрация новых пользователей
- Вход в систему
- Персональные настройки пользователя
- Темная/светлая тема оформления
- Поддержка русского и английского языков

### 📊 История поиска
- Сохранение истории поиска городов для каждого пользователя
- Отображение последних поисковых запросов
- Быстрый доступ к предыдущим поискам

### ⚙️ Админ-панель
- Полный контроль над всеми данными приложения
- Просмотр статистики использования
- Управление пользователями и их данными
- Мониторинг кэшированных данных

## 🛠️ Технические требования

- **Backend**: Django 5.2+ с ORM
- **База данных**: SQLite (по умолчанию)
- **Frontend**: HTML шаблоны с Bootstrap 5
- **API**: OpenWeatherMap API
- **Кэширование**: Встроенное кэширование в базе данных
- **Безопасность**: CSRF защита, валидация данных, защита API ключей

## 🚀 Установка и запуск

### 1. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 2. Настройка API ключа
Создайте файл `.env` в корне проекта и добавьте:
```env
OPENWEATHER_API_KEY=ваш_api_ключ_здесь
DEBUG=True
```

**Как получить API ключ:**
1. Зарегистрируйтесь на [OpenWeatherMap](https://openweathermap.org/api)
2. Получите бесплатный API ключ в личном кабинете
3. Добавьте ключ в файл `.env`

### 3. Настройка базы данных
```bash
# Создание миграций
python manage.py makemigrations

# Применение миграций
python manage.py migrate

# Создание суперпользователя (для админ-панели)
python manage.py createsuperuser
```

### 4. Запуск сервера
```bash
python manage.py runserver
```

Приложение будет доступно по адресу: http://127.0.0.1:8000/

Админ-панель: http://127.0.0.1:8000/admin/

## 🗃️ Модели данных

### WeatherTask
Задачи пользователей, связанные с погодой
- Поля: пользователь, город, текст задачи, статус выполнения, дата создания

### FavoriteCity
Избранные города пользователей
- Поля: пользователь, город, дата добавления

### CitySearchHistory
История поиска городов пользователями
- Поля: пользователь, город, дата поиска

### WeatherCache
Кэширование погодных данных
- Поля: город, данные погоды, время кэширования

### UserProfile
Настройки пользователя
- Поля: пользователь, язык интерфейса, тема оформления

## 🌐 API Endpoints

- `GET /` - Главная страница с поиском погоды
- `POST /` - Поиск погоды
- `GET /register/` - Регистрация пользователя
- `POST /register/` - Создание нового пользователя
- `GET /login/` - Страница входа
- `POST /login/` - Аутентификация пользователя
- `GET /logout/` - Выход из системы
- `GET /dashboard/` - Личный кабинет с задачами
- `POST /task/update/<id>/` - Обновление статуса задачи
- `POST /task/delete/<id>/` - Удаление задачи
- `GET /favorites/` - Управление избранными городами
- `GET /settings/` - Настройки пользователя
- `GET /admin/` - Админ-панель (только для суперпользователей)

## 🔒 Особенности безопасности

- **Защита API ключей**: Ключи хранятся в `.env` файле, исключенном из Git
- **CSRF защита**: Все формы защищены от межсайтовой подделки запросов
- **Аутентификация**: Личные данные доступны только владельцам
- **Валидация данных**: Проверка ввода на стороне сервера
- **SQL инъекции**: Защита через Django ORM

## 💾 Кэширование данных

- Погодные данные кэшируются на 2 часа
- При повторном запросе того же города данные берутся из кэша
- Автоматическое обновление при истечении срока кэша
- Снижение нагрузки на внешний API

## 🔧 Развертывание в продакшене

- Установите переменную `DEBUG=False` в `.env`
- Смените `SECRET_KEY` на случайную строку
- Настройте базу данных PostgreSQL для продакшена
- Соберите статические файлы: `python manage.py collectstatic`
- Используйте WSGI сервер (например, Gunicorn) с веб-сервером (Nginx)
